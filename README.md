# 智能日历

无构建静态版本，双击 `index.html` 即可在浏览器打开。

3 分钟演示脚本和完整验收清单见 [DEMO.md](./DEMO.md)。

## 已完成
- 项目基础壳：顶部栏、视图切换占位、月视图、右侧当日任务栏。
- 首屏即月视图，没有欢迎页。
- 今日高亮、周末区分、非本月日期淡化。
- 月视图任务条超过 3 条时折叠为 `+N`。
- 点击日期后选中，并显示当日任务。
- 日视图：0-24 小时时间轴，任务按开始/结束时间定位，重叠任务并排显示。
- 日视图当前时间红线，15 分钟 / 60 分钟粒度切换。
- 周视图：查看一周每天任务分布，点击某天进入日视图。
- 议程视图：按日期和时间顺序列出本周任务。
- 任务创建与编辑弹窗：标题、日期、起止时间、全天、优先级、颜色、标签、重复、提醒、地点、备注、子任务、完成状态。
- 点击已有任务可编辑，点击时间轴空白处可按 15 分钟粒度创建。
- 日视图任务块可上下拖拽改时间，底部手柄可拉伸改时长。
- 月视图、周视图任务可拖拽到其他日期实现跨日移动。
- AI 自然语言输入：可解析日期、时间、时长、优先级、提醒、标签，先显示确认卡片，确认后写入日历。
- 冲突检测：新任务与已有任务时间重叠时标红，并提供前移、后移、换天、拆分四种处理方案。
- 自动排程：输入多个待办，按空闲时间、优先级和截止时间自动生成可确认的排程草案。
- 目标驱动规划：输入长期目标，自动从今天倒推到截止日期，拆解阶段并生成每日学习任务。
- 目标看板：显示目标卡片、倒计时、完成进度环、阶段规划和已生成任务数。
- 主动式助理：今日行程、主动建议、连续未完成检测和未完成任务重排。
- 考试周模式：一键开启冲刺节奏，显示每日必做三件事。
- 情绪与压力感知：记录 1-5 分心情和压力来源，判断压力等级并给出温和建议。
- 课表导入：粘贴 CSV/文本课表，按“课程名、地点、星期、开始、结束、教师”解析并预览后导入。
- 空闲时间自动分配：为下一周工作日自动排入自习/作业和午间运动。
- 校园食堂：录入真实食堂与步行时间，按距离推荐，不编造数据。
- 健康建议：录入身高、体重、年龄、性别和目标，估算 BMI 并给出运动饮食建议。
- 总协调建议：检测时间冲突，并按课程、考试、健康、长期目标、娱乐给出优先级提示。
- 数据导入导出：支持 JSON 和 ICS 导出/导入，数据默认仅存当前浏览器。
- 一键清空全部本地数据。
- PWA 离线：提供 `manifest.json` 和 `sw.js`，通过本地 HTTP 服务打开后可离线使用并安装。
- 浏览器通知：可申请通知权限并发送测试通知。
- AI 服务设置：可选择本地规则、OpenAI 或 DeepSeek，并保存模型与 API Key。
- 未完成目标自动顺延：打开页面时，过期的未完成目标会自动移到最近空档。
- AI 语音通话：在助理页可开始语音通话，支持查日程、创建任务、重排目标和记录心情。
- 本地持久化：使用 `localStorage` 保存任务与选中日期，刷新不丢。
- 深色 / 浅色主题切换。
- 键盘快捷键：`T` 回到今天，`M/D/W/A` 切换月/日/周/议程。
- 视图可通过 URL 参数直达：`index.html?view=day`、`week`、`agenda`。

## 验证步骤
1. 打开 `index.html`，首屏应直接显示月历。
2. 确认今日日期有高亮圆圈，周末日期文字颜色不同，非本月日期变淡。
3. 点击带任务条或任务圆点的日期，右侧应显示该日任务。
4. 点击“今天”按钮或按 `T`，应回到当前月并选中今天。
5. 点击右上角“深色”，主题切换后刷新页面应保持。
6. 刷新页面，选中日期和示例任务应仍在。
7. 点击顶部“日”，应看到 0-24 时间轴和当前时间红线，今日示例任务显示在对应时间。
8. 在日视图切换“15 分 / 60 分”，时间轴网格粒度应变化。
9. 点击顶部“周”，应看到本周每天任务分布；点击某天进入日视图。
10. 点击顶部“议程”，应按日期和时间列出本周任务。
11. 点击右下角 `+` 新建任务，填写标题和起止时间后保存，任务应出现在对应日期。
12. 在日视图点击时间轴空白位置，应弹出以该时间点开始的新建任务窗口。
13. 在日视图按住任务块上下拖动，应改变开始/结束时间；拖动底部手柄应改变时长。
14. 在月视图或周视图，把任务条拖到另一天，应完成跨日移动。
15. 点击任务打开编辑，修改颜色、标签、优先级、子任务或勾选完成，保存后刷新页面数据仍保留。
16. 在顶部输入“明天下午 3 点和产品评审，1 小时，提前 10 分钟提醒，重要”，点击“生成”，应显示预览卡片。
17. 确认预览后，任务应写入对应日期；再次刷新页面，该任务仍存在。
18. 输入一个与今日已有任务重叠的新任务，确认后应弹出冲突提示，显示前移、后移、换天、拆分四个方案。
19. 在顶部输入“本周要完成论文、健身、开会”，点击“自动排程”，应显示三个任务的排程预览。
20. 确认自动排程后，三个任务应分别写入空闲时段，刷新不丢。
21. 点击顶部“目标”，点击“新建目标”，填写“12月通过六级英语考试”、截止日期、目标结果、每日时长和最早开始时间。
22. 点击“生成计划”，应显示阶段拆解和每日任务示例；确认后生成每日学习任务。
23. 回到“目标”视图，应看到目标卡片、倒计时、进度环和阶段规划。
24. 点击顶部“助理”，应看到主动提醒设置、今日行程、主动建议、考试周模式、情绪记录和当前状态。
25. 在助理页选择心情分数，应保存心情记录并更新压力等级。
26. 点击“开启考试周模式”，应显示每日必做三件事；再次点击可关闭。
27. 在助理页“课表导入”粘贴两行课程数据，点击“解析并预览”，应显示课程列表；确认后写入日历。
28. 点击“自动分配空闲时间”，应生成下一周的自习和午间运动任务。
29. 录入身高、体重、年龄后点击“生成建议”，应显示估算 BMI 和运动饮食建议。
30. 添加一个食堂和步行分钟，列表应显示最近推荐。
31. 在助理页“数据与隐私”点击“导出 JSON”和“导出 ICS”，应下载对应文件。
32. 选择导出的 JSON 或 ICS 文件导入，任务和设置应恢复。
33. 点击“清空全部数据”并确认，本地任务、目标、心情等数据应清空。
34. 在助理页点击“开始语音通话”，允许麦克风权限后，可语音询问今日安排、创建任务或重排目标。
35. 存在过期未完成目标时重新打开页面，任务应自动顺延到最近空档。

## PWA 运行方式

双击文件虽然可以直接使用，但浏览器通知、Service Worker 离线缓存和安装功能需要 HTTP 环境：

```powershell
cd C:\Users\17174\Documents\Codex\2026-09-14\new-chat\outputs\smart-calendar
python -m http.server 8000
```

然后访问 `http://localhost:8000/index.html`。

## 当前限制
- 当前 AI 解析、自动排程、目标拆解和主动建议均为本地规则实现，未接入 OpenAI/DeepSeek API；地图、天气、真实食堂菜单和可穿戴设备尚未接入。
