智能日历 - 使用与分享说明

一、快速打开
1. 直接双击 index.html，即可在浏览器打开月历。
   提示：语音排程功能需要先启动后端，见下面第二步。

二、启用语音排程（需要 Python）
1. 安装 Python 3.10 或更高版本。
2. 在本文件夹打开命令行，运行：
   python server.py
3. 浏览器访问：http://127.0.0.1:8000

三、启用真实 AI（可选）
如果只想要演示效果，可以跳过这一步，系统会使用内置规则生成计划草案。
如果要接入大模型，先设置环境变量再运行 server.py：

   Windows PowerShell:
   $env:LLM_API_KEY="你的Key"
   python server.py

   AI Key 只保存在服务端，不会写进网页。

四、如何分享
把整个“智能日历”文件夹压缩成 zip 发给别人即可。
对方解压后：
   - 只看日历：双击 index.html
   - 用语音排程：运行 python server.py，再访问 http://127.0.0.1:8000

五、主要功能
   - 月视图，上下滑动或滚动切换月份
   - 点击日期查看当天日程
   - 右下角 + 号添加日程
   - 语音按钮用自然语言生成任意计划，确认后批量加入日历
