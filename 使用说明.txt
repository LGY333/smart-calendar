AI学习规划助手 - 使用与分享说明

一、快速运行（需要 Python）
1. 安装 Python 3.10 或更高版本。
2. 在本文件夹打开命令行，运行：
   python server.py
3. 浏览器访问：http://127.0.0.1:8000

说明：server.py 会直接提供已经构建好的网页（dist 目录），
无需安装 Node 也能使用。

二、启用 AI（可选）
如果只想要演示效果，可以跳过这一步，系统会使用内置规则生成计划。
如果要接入大模型，先编辑本目录的 config.json：
   {
     "api_key": "你的DeepSeek Key",
     "base_url": "https://api.deepseek.com/v1",
     "model": "deepseek-chat"
   }
API Key 只保存在本地，不会写进网页，也不会提交到代码仓库。

三、重新开发前端（需要 Node）
如果要修改前端源码，需要 Node.js：
1. npm install
2. npm run build
3. 重新运行 python server.py

四、如何分享
把整个"智能日历"文件夹压缩成 zip 发给别人即可。
对方解压后运行 python server.py，再访问 http://127.0.0.1:8000。

五、主要功能
   - 月视图日历，今日高亮，任务按课程/运动/AI推荐分类
   - AI 智能诊断与拆解，按遗忘曲线自动生成每日计划
   - 一键生成学习物料：背单词、做真题、知识框架思维导图
   - 学习知识库：上传课件、教材、错题本
   - OPC 学业审计看板、一键演示模式、导出学习报告
